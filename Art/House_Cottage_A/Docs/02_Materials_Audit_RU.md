# Существующие материалы — предварительная оценка

Источник: `CozySettlement/Mat`. 77 файлов в 11 папках; полный список,
разрешения и режим каналов — `QA/material_inventory.json`.
Сравнительный лист — `QA/material_contact_sheet.jpg`.
BaseColor осмотрены визуально. Совместимость Normal/Roughness/Height между собой,
тайлинг и вид в движке ещё не проверены. На серую модель эти карты не назначены.

| Набор | Оценка / предполагаемое использование |
|---|---|
| T_Plaster | Подходящая тёплая база. Проверить масштаб пятен, снизить Normal при необходимости. |
| T_Timber | Волокна идут горизонтально на карте. Для балки направлять UV вдоль её длины; ослабить резкие тёмные трещины. |
| DoorWood | Подходит по назначению. Доски вертикальные; вблизи выглядит достаточно реалистично, потребуется проверка контраста. |
| Shutters | Можно переиспользовать для ставней; проверить согласование цвета с DoorWood. |
| RoofTile | Изображение одной плитки с внешним светлым фоном. Нужна точная посадка UV внутри поверхности и проверка краевого padding; это не готовая бесшовная карта крыши. Грязь может оказаться слишком контрастной. |
| T_FieldStone | Изображает целую кладку. Нельзя покрывать каждый объёмный камень всей картой. Выбрать отдельные области камня или подготовить согласованный atlas позднее. |
| T_ChimneyStone | Аналогично: карта кладки для плоского участка, а не готовая развёртка единичного камня. Сохранить палитру, проверить варианты UV. |
| Logs_Bark | Более фотографическая кора; не подходит для чистых рубленых балок. Возможна только поздняя оценка для дров. |
| Bark | Стилизованная кора уже использовалась у дерева. Балкам кора не нужна; кандидат для дров/пней. |
| T_Foliage | Готовые группы листьев; кандидат для будущей растительности. Не является готовым модулем плюща или материалом цветков. |
| Тест | Вложенные фотографические bark/concrete-наборы. Для этого этапа не используются. |

В Mat не найдены отдельные именованные наборы металла и стекла. Их можно будет
сначала решить параметрическими материалами, без генерации новых текстур.
Также нет явно выделенных наборов цветов и почвы/дорожек. Для декора сначала
проверить уже созданные модули и палитры Oak_Kit, фонарь и скворечник в Art/Props.

В основных наборах имеются BaseColor, Normal, Roughness, AO; во многих Height,
в части Gloss. Не подключать одновременно Gloss и Roughness как одинаковые карты.
BaseColor — sRGB; Normal, Roughness, AO, Height — данные, без sRGB.
Normal orientation и игровые настройки подтверждаются только на этапе импорта.

На этом этапе новые текстуры не создавались, существующие файлы не менялись.
