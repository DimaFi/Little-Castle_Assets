- Yard/v004/Cottage_Yard_Kit.blend — галерея 17 предметов, четыре с материалами.

Библиотеки материалов добавлять через File → Append → Material.
Материал верёвки — процедурные полосы волокон по UV0, без displacement,
roughness 0.94, лёгкий bump 0.6 мм / strength 0.12. Перед экспортом его нужно запечь.
Камни используют безопасные фрагменты исходной карты без нарисованных швов.
Дерево развёрнуто вдоль деталей, ворот — цилиндрически с отдельными торцами.
Все используемые изображения встроены в .blend. UV0 не является lightmap.

У черепицы колодца восстановлена толщина внутрь, края конька подогнаны к скатам.
Ручка ведра сужена на 10% по X и опущена на 25 мм для контакта с верхним обручем.
Остальная геометрия и расположение сохранены. QA/well_bucket_v020_readback.json:
повторное открытие четырёх файлов, проверка геометрии, UV и встроенных карт.
Крупные планы просмотрены в Renders/Checkpoint_15/v020.
