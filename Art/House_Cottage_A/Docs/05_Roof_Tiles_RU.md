# v006 — черепица, ограниченный этап

Исходник: `Source/Refinement/v005/House_Cottage_A.blend`.
Текущая сборка: `Source/Roof/v006/House_Cottage_A.blend`.

Добавлены 477 плиток на двух главных скатах, 70 на люкарне и 27 элементов
конька (20 больших и 7 малых). Черепица имеет толщину и слегка выпуклый профиль.
11 рядов на каждом главном скате идут снизу вверх со смещением на полплитки.
Ряды перекрываются, случайных вращений нет. Вариация высоты — только 0–3 мм.

Восемь общих шаблонов обслуживают основную раскладку, включая узкие торцевые
плитки и укороченный верхний ряд. У примыканий сделана отдельная подрезка.
Плитки люкарны деформированы по её поверхности; эти небольшие детали уникальны.
Вся новая геометрия добавляет 22 168 треугольников до последующей оптимизации.
Проверка не обнаружила вырожденных треугольников: `QA/roof_v006.json`.

## Где редактировать

Внутри `05_ROOF`:

- `ROOF_TILES_MAIN`: основные ряды. `SM_Tile_<сторона>_<ряд>_<номер>`.
- `ROOF_TILES_DORMER`: подогнанная черепица слухового окна.
- `ROOF_RIDGE_CAPS`: объёмные полукруглые коньковые элементы.

Шаблоны `SM_RoofTile_Shared_*` и `SM_Roof_RidgeCap_Shared_A` находятся в скрытой
`80_MODULE_LIBRARY`. В Edit Mode связанного экземпляра изменяются все плитки,
использующие ту же mesh data. Для уникальной правки сначала Make Single User.
Основные скаты и примыкания из v005 сохранены как отдельные объекты под плитками.

Рендеры: `Renders/Checkpoint_03/v006/01_Hero.png` и `02_Roof_Close.png`.
Это серая геометрическая итерация, без UV, материалов, LOD и игровых экспортов.
Следующий проход: проверить крайние и подрезанные плитки с других направлений,
затем продолжать стены/каркас/дверь. Развёртка и материалы выполняются позже.

## Повторный запуск

```powershell
& 'C:\Program Files\Blender Foundation\Blender 4.4\blender.exe' -b --factory-startup --python Art\House_Cottage_A\Scripts\07_build_roof_tiles.py -- --revision v007
```

Запуск из корня CozySettlement, всегда с новым именем версии. Скрипт читает v005
и не подхватывает ручные изменения текущей крыши. Для ручных правок — Save As.
Предыдущие версии не изменены.
