# v005 — короткий проход: примыкания и фундамент

Источник: сохранённая сцена `Source/Blockout/v004/House_Cottage_A_Blockout.blend`.
Результат: `Source/Refinement/v005/House_Cottage_A.blend`.
Предыдущие версии не перезаписывались. Материалы по-прежнему серые.

## Что изменилось

- Передняя стенка люкарны теперь опускается чуть ниже поверхности ската.
  Боковые щёки соединяют переднюю стенку с кровлей. Окно сохранено отдельными частями.
- Профиль маленькой крыши сглажен. Её задний край рассчитан отдельно в каждой
  точке по реальному пересечению с изогнутым основным скатом. Прямоугольный
  выступающий задний край старой люкарны удалён.
- В основном скате есть настоящий вырез под люкарной, передний фартук
  `SM_Dormer_FrontApron_A` и полоса примыкания `SM_Dormer_ValleyFlashing_A`.
- Весь дымоход сдвинут на 26 см внутрь по X, от края фронтона. Ось шахты
  постоянная: X=-2.94 м, Y=0.72 м; случайные повороты рядов убраны.
- Под трубой вырезано отверстие, добавлен отдельный воротник
  `SM_Chimney_RoofCollar_A`: нижняя часть повторяет уклон, верхняя подходит к шахте.
- Для фундамента созданы три общих mesh-варианта камня. 80 экземпляров образуют
  два ряда со смещёнными швами. На углах направление длинного камня меняется
  через ряд. Верхний ряд не пересекает входной проём.

Новые исходные камни `SM_Foundation_Stone_A/B/C` находятся в скрытой коллекции
`80_MODULE_LIBRARY` текущей сцены. Их можно взять через File → Append → Object
из текущего .blend. Изменения Edit Mode отражаются на связанных экземплярах.
Их отдельная библиотека: `Source/Modules/v003/Foundation_Stones.blend` (Append → Object).

## Проверка

`Renders/Checkpoint_02/v005`: один общий вид и три крупных плана.
`QA/refinement_v005.json`: геометрическая проверка, количество объектов,
число камней, вертикальность рядов трубы и численная проверка линии
пересечения люкарны с основной крышей. Это не проверка импорта в движок.
Оба отверстия дополнительно проверены лучами в сохранённой сцене; контрольные
лучи вне отверстий пересекают сохранившиеся скаты. Проверка выполнена скриптом
`06_validate_refinement.py`, который также сохранил отдельную библиотеку камней.
Все четыре рендера осмотрены: общий вид, люкарна, труба, угловая перевязка цоколя.

Модификаторы основного ската применены перед Boolean, чтобы вырезать отверстия
в замкнутой оболочке, а не в бесконечно тонкой поверхности. Скаты остаются
раздельными mesh-объектами. Основная форма крыши взята из v004.

Остаётся: ряды черепицы с подрезкой вокруг этих узлов, конструктивная детализация
стен и каркаса, дверь/ставни, UV, материалы и оптимизация. Планки примыкания пока
геометрические серые элементы; материал металла появится на этапе материалов.
Фундамент — следующий геометрический проход, пока без UV и финальной оптимизации.

## Повторение

Из корня CozySettlement:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 4.4\blender.exe' -b --factory-startup --python Art\House_Cottage_A\Scripts\05_refine_junctions.py -- --revision v006
```

Нужно новое имя версии. Скрипт всегда берёт исходную v004, не читает ручные
правки v005. Для дальнейшей ручной работы открыть актуальную сцену и Save As.
Не запускать генератор внутри несохранённой сцены Blender.
