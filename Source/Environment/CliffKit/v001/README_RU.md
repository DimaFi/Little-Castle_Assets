# CliffKit v001 — скалы, валуны и пешеходные подъёмы

14 типов, три авторских LOD на каждый, 42 FBX. Blender 4.4.3, метрические единицы,
Z-up в исходнике; в Unity Y-up, +Z в сторону верхнего рельефа. Pivot — центр
подножия. Нижняя юбка уходит на 0.45 м ниже pivot и должна быть скрыта землёй.
Галерея исходников разнесена только в `.blend`; каждый FBX экспортирован из нуля.

Реальный импорт в Unity выявил handedness conversion: FBX без адаптера направлен
по -Z. `CliffKitAssetIntake` нормализует каждый дочерний LOD поворотом 180° по Y;
публичный prefab и его сокеты направлены по +Z. Исходный экспорт сохраняется
неизменным. Подключать именно проверенные prefabs, не сырой FBX напрямую.

Сначала изучены переданный CODEX_START_HERE, GitHub handoff ветки
gpt6/cliffkit-authoring-prototype-v001 и Q08 issue #37 игры. Исходный прототип
сохранён в Tools/CliffKit_Prototype_v001; текстуры сохранены здесь без изменения
байтов. Новый воспроизводимый рецепт и QA — Tools/CliffKit_v001.

Доработки: замкнутые объёмы, наружные нормали, UV по доминирующей плоскости,
разная ширина выступов, неровный гребень, спокойные травяные поверхности,
одно определение формы для всех LOD, общие боковые границы и сокеты.
Никаких Blender modifiers или runtime simplification в игре не требуется.

`QA/geometry.json` фиксирует настоящие 42 FBX roundtrip, отсутствие открытых
рёбер, вырожденных треугольников и UV. `QA/ARCHETYPES.jpg` и
`QA/LOD_CONTACT_SHEET.jpg` — фактические Cycles-рендеры. Для каждого типа
сохранены front/rear и три LOD. Первая визуальная итерация показала слишком
равномерные вертикальные блоки и потерю выступов на дальнем LOD; это исправлено.
Это модульная основа для выбранных уступов; полная художественная приёмка
в процедурном мире и Player-профилирование остаются отдельными проверками.

17 исходных карт — tileable prototype, не сканы. AO_Approx не является baked AO.
Height/MossMask сохранены для дальнейшей авторской работы; runtime пакет содержит
только BaseColor, OpenGL normal, Roughness, AO. FBX не переносит Blender node graph.
Общий LC Stylized Lit принимает roughness напрямую; преобразование в Standard
smoothness здесь не нужно. Травяная крышка — жёсткая поверхность земли, без ветра.

Cliff_Straight_A/B, Convex/Concave, Terrace_Low/High, End_Left/Right образуют
разные высоты и кривизны. Соединение без зазора гарантируется только для
одинаковой высоты/размеров боковой контактной линии. Разные высоты стыкуются
через рельеф/террасы, а не случайным смещением. Угловые/end-профили имеют свои
контактные кривые: прямоугольный Unity validator их не утверждает автоматически.

Ramp_Hike_A: 7×24 м, подъём 6.5 м; Ramp_Hike_B: 9×32 м, подъём 9 м.
Ровный центральный коридор шириной 3.5/4.5 м. Номинальный уклон 15.15/15.71°.
Это декоративная оболочка. Настоящий terrain обязан дать такой же подъём,
вход/выход, slope и clearance. Предложения 30° для пехоты и 12° для телег
передаются параметрами; глобальные игровые правила не меняются.

Не помещать Tools или .blend в Unity. Выпуск создаётся через package.py после
проверки исходников и фиксирует source commit/SHA256 каждого payload.
Не пересобирать опубликованный v001 на месте; изменения искусства требуют v002.

```powershell
& 'C:\Program Files\Blender Foundation\Blender 4.4\blender.exe' --factory-startup -b --python Tools/CliffKit_v001/build.py
& 'C:\Program Files\Blender Foundation\Blender 4.4\blender.exe' --factory-startup -b --python Tools/CliffKit_v001/qa_render.py
python Tools/CliffKit_v001/verify.py
```
