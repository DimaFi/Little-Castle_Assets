# Church_A — геометрия v002

Редактируемый исходник: `Church_A.blend`. Метровый масштаб, Z вверх, вход со стороны −Y, колокольня строго сзади по оси X = 0.

Это стадия моделирования без покраски. В сцене один нейтральный серый материал. Финальные UV, текстуры, LOD и экспорт в игру не выполнялись.

## Исправления по замечаниям

- Цоколь собран из более широких камней готовой модели заборчика `SM_StoneWall_A`, с перевязкой боковых рядов. Этот же исходный камень использован в обрамлениях и кладке башни.
- Козырёк снижен, окно поднято. Между самой высокой точкой козырька и низом каменного подоконника оставлен проверяемый зазор.
- Убраны совпадающие поверхности на углах корпуса; открытый ярус башни построен единой замкнутой оболочкой с четырьмя прорезанными арками.
- Ствол башни заканчивается ниже открытого яруса. Стык закрыт площадкой и каменным поясом, поверхности ярусов не накладываются.
- Башня сдвинута за полностью завершённый задний край основной крыши. Короткое закрытое соединение связывает основания зданий ниже крыши.

## Повторное использование

- Камни: `CozySettlement/Art/House_Cottage_A/Source/Yard/v011/Modules/SM_StoneWall_A/SM_StoneWall_A.blend`, объект `Wall_Stone`.
- Балки: `Source/Modules/v002/Cottage_A_Primitives.blend`, сохранён изгиб при сокращении промежуточных сечений.
- Черепица и конёк: `Source/Openings/v007/House_Cottage_A.blend`; черепица упрощена до замкнутого элемента из 20 треугольников.
- Стрельчатые окна, дверь и полый колокол построены для церкви.

Все используемые сетки находятся внутри нового `.blend`; файл не требует подгрузки старого дома. Скрипт повторной сборки использует исходные локальные ассеты по указанным путям.

## Проверка

`geometry_report.json` содержит подсчёт всей установленной геометрии с модификаторами. `readback_qa.json` — независимую проверку сохранённого файла: замкнутость сеток, вырожденные треугольники, ось башни и зазоры.

Камеры и рендеры: общий вид, задний вид, фасад, вход крупно, боковой вид для проверки положения башни. Коллекция `90_STUDIO` не относится к игровой модели.

Сборка: Blender 4.4, `--background --factory-startup --python build_church.py`.
Проверка: Blender 4.4, `--background --factory-startup --python validate_church.py`.
