ЗАДАЧА

Нужно создать полноценную игровую 3D-модель дерева Tree02 для проекта CozySettlement.

Это НЕ новый концепт.
Дизайн дерева уже утверждён.

Нужно использовать ВСЕ подготовленные материалы проекта:

1. концепт-арт Tree02;
2. изображение итогового вида дерева;
3. ортографические ракурсы:
   - спереди;
   - сзади;
   - слева;
   - справа;
   - сверху;
   - снизу;
4. крупные планы:
   - ствол;
   - кора;
   - корни;
   - ветки;
   - крона;
5. подготовленные текстуры Tree02;
6. существующий визуальный стиль проекта CozySettlement.

Главное требование:
НЕ переосмысливать дерево и НЕ создавать другой вариант.
Модель должна максимально точно повторять утверждённый Tree02.

--------------------------------------------------
1. ОБЩИЙ ВИЗУАЛ
--------------------------------------------------

Стиль игры:

- уютная стилизованная графика;
- мягкий hand-painted / stylized PBR;
- визуально близко к Tiny Glade;
- формы читаемые;
- без фотореализма;
- без чрезмерной детализации;
- без слишком большого количества мелкой геометрии;
- модель должна красиво смотреться с игровой камеры сверху/под углом;
- силуэт должен хорошо читаться даже на среднем расстоянии.

Tree02 отличается от первого дерева.

Главные особенности Tree02:

- толстый выразительный ствол;
- ствол слегка закручен;
- выраженная S-образная форма;
- крупные корни выходят из земли;
- корни являются частью силуэта дерева;
- ствол постепенно разделяется на несколько крупных ветвей;
- ветви расположены асимметрично;
- крона состоит из отдельных крупных масс;
- крона НЕ должна выглядеть одним шаром;
- между группами листьев должны быть видны просветы;
- листья крупные и стилизованные;
- листва светло-зелёная / жёлто-зелёная;
- дерево выглядит тёплым, уютным и немного сказочным;
- возле основания допускаются мох и небольшие растения.

НЕ делать:

- реалистичное лесное дерево;
- миллионы мелких листьев;
- случайно разбросанные planes;
- симметричную крону;
- идеально прямой ствол;
- очень тонкие ветви;
- слишком острые формы;
- гиперреалистичную кору;
- чрезмерное количество полигонов.

--------------------------------------------------
2. ПРОПОРЦИИ
--------------------------------------------------

Ориентироваться на утверждённые изображения.

Примерный игровой размер:

Height:
4.5–6 метров.

Ширина кроны:
примерно 65–90% высоты дерева.

Основание ствола:
массивное.

Ствол к середине постепенно сужается.

Корни должны быть достаточно большими, чтобы их форма читалась с игровой камеры.

Нельзя делать корни маленькими декоративными полосками.

Пример:

основной ствол
↓
крупное основание
↓
5–8 выраженных корневых направлений

Не нужно делать одинаковые корни по кругу.

--------------------------------------------------
3. СТВОЛ
--------------------------------------------------

Создать отдельную качественную геометрию ствола.

Название:

SM_Tree02_Trunk

Ствол должен:

- иметь крупную органическую форму;
- немного закручиваться;
- иметь различную толщину;
- избегать идеального цилиндра;
- иметь немного неровный силуэт;
- плавно соединяться с корнями;
- иметь правильные переходы в крупные ветви.

ВАЖНО:

Основной объём создаётся геометрией.

Текстура Normal НЕ должна компенсировать плохую форму модели.

Большие изгибы и выступы:
геометрия.

Средняя фактура:
Normal.

Мелкая кора:
DetailNormal.

--------------------------------------------------
4. КОРНИ
--------------------------------------------------

Корни — важнейшая часть Tree02.

Сделать их отдельными выразительными формами.

Желательно:

5–8 основных корней.

Они должны:

- выходить из ствола естественно;
- постепенно уходить в землю;
- иметь разную длину;
- иметь разную толщину;
- частично закручиваться;
- немного пересекаться визуально;
- создавать красивое основание дерева.

Нельзя:

делать звезду из одинаковых корней.

Переход:

ствол → корень

должен выглядеть плавным.

--------------------------------------------------
5. ВЕТВИ
--------------------------------------------------

Разделить систему ветвей минимум на:

Primary branches
Secondary branches
Small supporting branches

Основные ветви являются частью силуэта.

Создать примерно:

5–8 крупных ветвей.

Каждая крупная ветвь:

- имеет собственное направление;
- плавно выходит из ствола;
- становится тоньше к концу;
- слегка искривляется;
- поддерживает отдельную массу кроны.

Не создавать procedural-chaos из сотен ветвей.

Особенно важно:

ветки должны объяснять, почему листва находится именно там.

--------------------------------------------------
6. КРОНА
--------------------------------------------------

Не создавать крону как один объект-шар.

Крона Tree02 должна состоять приблизительно из:

6–10 крупных визуальных кластеров.

Например:

LeafCluster_A
LeafCluster_B
LeafCluster_C
LeafCluster_D
LeafCluster_E
LeafCluster_F

Дополнительно несколько маленьких кластеров.

Кластеры:

- различного размера;
- немного пересекаются;
- имеют просветы;
- повторяют утверждённый концепт;
- создают асимметричный силуэт.

Самая важная задача:

с расстояния крона должна восприниматься красивыми крупными формами.

--------------------------------------------------
7. ЛИСТЬЯ
--------------------------------------------------

Использовать подготовленный atlas:

Tree02_Leaves_BaseColor
Tree02_Leaves_Normal
Tree02_Leaves_Roughness
Tree02_Leaves_AO
Tree02_Leaves_Opacity
Tree02_Leaves_Thickness
Tree02_Leaves_Transmission
Tree02_Leaves_WindMask
Tree02_Leaves_GradientMask
Tree02_Leaves_ORM

Листья НЕ размещать случайным образом.

Это крайне важно.

У каждого листа должна быть понятна ориентация:

основание
↓
находится около ветки

кончик
↓
направлен наружу от ветки

То есть лист должен визуально "расти" из ветки.

Нельзя:

- случайные повороты 360°;
- листья вверх ногами;
- хаотические planes;
- одинаковая ориентация всех карточек.

Использовать контролируемое распределение.

Допускается variation:

Scale ±15–25%
Rotation around growth direction ±15–25°
Color variation — очень слабая.

--------------------------------------------------
8. LEAF CARDS
--------------------------------------------------

Листва должна быть оптимизированной.

Создавать leaf cards / небольшие leaf clusters.

Не нужно делать каждый лист сложной 3D-моделью.

Предпочтительно:

несколько типов карточек:

LeafCard_A
LeafCard_B
LeafCard_C

и несколько готовых групп:

LeafCluster_A
LeafCluster_B
LeafCluster_C
...

Карточки должны иметь:

- минимум пустого пространства;
- правильную Alpha/Opacity;
- правильные normals;
- двухсторонний материал;
- корректную ориентацию.

--------------------------------------------------
9. ВЕТЕР
--------------------------------------------------

Использовать:

Tree02_Leaves_WindMask
Tree02_Leaves_GradientMask

Логика:

основание листа:
почти неподвижно

середина:
небольшое движение

кончик:
наибольшее движение

Основные ветки:

почти неподвижны.

Вторичные ветки:

очень слабое движение.

Листва:

заметное, но мягкое движение.

НЕ делать:

сильную тряску всего дерева.

Цель:
очень спокойный ветер.

--------------------------------------------------
10. TRANSLUCENCY ЛИСТВЫ
--------------------------------------------------

Использовать:

Tree02_Leaves_Thickness
Tree02_Leaves_Transmission

Листья должны красиво реагировать на контровой солнечный свет.

При солнце сзади:

края и тонкие части листьев становятся немного светлее.

Но НЕ превращать листья в glowing/neon.

Эффект очень мягкий.

--------------------------------------------------
11. КОРА
--------------------------------------------------

Использовать полный набор:

Tree02_Bark_BaseColor
Tree02_Bark_Normal
Tree02_Bark_Roughness
Tree02_Bark_AO
Tree02_Bark_Height
Tree02_Bark_DetailNormal
Tree02_Bark_DetailRoughness

Материал:

M_Tree02_Bark

Основная текстура отвечает за:

крупный рисунок коры.

DetailNormal:

маленькие борозды.

DetailRoughness:

микровариацию поверхности.

НЕ использовать DetailNormal слишком сильно.

Кора должна остаться мягкой и стилизованной.

--------------------------------------------------
12. UV СТВОЛА
--------------------------------------------------

Особое внимание UV.

Не растягивать кору.

Направление текстуры:

в основном вдоль роста дерева.

На:

стволе
крупных ветках
корнях

рисунок должен следовать направлению геометрии.

Избегать:

резких швов;
огромных изменений texel density;
сильно растянутых участков.

--------------------------------------------------
13. МАТЕРИАЛ МХА
--------------------------------------------------

Использовать:

Tree02_Moss_BaseColor
Tree02_Moss_Normal
Tree02_Moss_Roughness
Tree02_Moss_AO
Tree02_Moss_Opacity
Tree02_Moss_ORM

Название материала:

M_Tree02_Moss

Мох использовать только локально.

Основные места:

- нижняя часть ствола;
- углубления между корнями;
- отдельные участки коры;
- теневые стороны дерева.

Не покрывать мхом всё дерево.

Мох должен быть акцентом.

--------------------------------------------------
14. НИЖНЯЯ РАСТИТЕЛЬНОСТЬ
--------------------------------------------------

Использовать:

Tree02_GroundPlants_BaseColor
Tree02_GroundPlants_Normal
Tree02_GroundPlants_Roughness
Tree02_GroundPlants_AO
Tree02_GroundPlants_Opacity
Tree02_GroundPlants_ORM

Материал:

M_Tree02_GroundPlants

Создать несколько небольших модульных кустиков:

GP_A
GP_B
GP_C
GP_D
...

Использовать только часть вокруг дерева.

Не превращать Tree02 в огромную клумбу.

Растения должны подчёркивать основание дерева.

--------------------------------------------------
15. ORM
--------------------------------------------------

Использовать упакованные карты:

Tree02_Leaves_ORM
Tree02_Moss_ORM
Tree02_GroundPlants_ORM

Структура:

R = Ambient Occlusion
G = Roughness
B = Metallic

Для этих материалов Metallic должен быть 0.

Если создаётся Bark ORM:

Tree02_Bark_ORM

использовать ту же схему.

--------------------------------------------------
16. МАТЕРИАЛЫ
--------------------------------------------------

Создать отдельные материалы:

M_Tree02_Bark
M_Tree02_Leaves
M_Tree02_Moss
M_Tree02_GroundPlants

Не создавать десятки материалов.

Стремиться к минимальному количеству material slots.

--------------------------------------------------
17. NORMALS
--------------------------------------------------

Очень важно для стилизованной графики.

Проверить:

- smooth shading;
- правильные face normals;
- отсутствие hard shading artifacts;
- leaf cards должны визуально восприниматься частью общей кроны.

Для листвы при необходимости использовать:

custom normals / averaged normals

чтобы карточки не выглядели отдельными плоскостями.

--------------------------------------------------
18. ТОПОЛОГИЯ
--------------------------------------------------

Топология должна быть игровой.

Не использовать без необходимости:

- sculpt mesh на миллионы полигонов;
- dense subdivision;
- очень маленькие полигоны;
- скрытую геометрию внутри ствола.

Ствол:

достаточно геометрии для красивого силуэта.

Внутренняя поверхность:

минимальная.

--------------------------------------------------
19. LOD
--------------------------------------------------

Подготовить:

LOD0
LOD1
LOD2
LOD3

Примерная логика:

LOD0:
100% модели.

LOD1:
примерно 55–70% геометрии.

LOD2:
примерно 25–40%.

LOD3:
примерно 10–20%.

При уменьшении:

СНАЧАЛА удалять мелкие детали.

НЕ менять основной силуэт дерева.

Для листвы:

постепенно объединять/уменьшать количество кластеров.

--------------------------------------------------
20. NANITE
--------------------------------------------------

Ствол потенциально можно использовать с Nanite.

Но Alpha foliage не строить вокруг предположения, что Nanite решит всё автоматически.

Листва должна оставаться эффективной сама по себе.

--------------------------------------------------
21. COLLISION
--------------------------------------------------

Создать простую collision geometry.

Игроку не нужна точная collision каждой ветки.

Collision должна покрывать:

- основной ствол;
- крупное основание;
- при необходимости самые большие корни.

Не создавать collision для каждого листа.

--------------------------------------------------
22. PIVOT
--------------------------------------------------

Pivot главной модели:

по центру основания дерева на уровне земли.

То есть:

X/Y = центр ствола
Z = уровень земли

Это важно для procedural world generation.

--------------------------------------------------
23. SCALE
--------------------------------------------------

Работать в реальном масштабе.

Unreal:

1 Unreal Unit = 1 cm.

Модель после импорта не должна требовать Scale 10 / Scale 100.

Export scale:

1.0

Tree02_Trunk

Tree02_LeafClusters

Tree02_Variant_C

25. ВАРИАЦИИ

Но структура должна позволить потом менять:

- расположение LeafClusters;
- размер кроны;
- небольшое направление ветвей;
- количество мха;
- растения вокруг основания.

НЕ создавать вариации до завершения основной модели.
