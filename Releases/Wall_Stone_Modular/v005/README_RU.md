## Внутренняя сторона и открывание

В Unity локальная **+X — внутренняя сторона**, −X — внешняя. Металлические
полосы и ручки находятся внутри. Левые/правые имена определены координатами
Z, а не видом с любой камеры. Оси петель: `(0.60,0,-1.04)` и `(0.60,0,+1.04)`.
Левая створка открывается Y 0→+90°, правая 0→−90°, обе в +X.

Пользовательский сдвиг +0.421571 м был в правильную сторону, но тест выявил
пересечения. +0.57 м также не хватало. При +0.60 м тест обеих створок во всех
трёх LOD, 0..90° с шагом 0.5°, не обнаружил пересечений треугольников с рамой.
Результаты в `QA/gate_sweep.json`. Это дискретная проверка геометрии, не
симуляция Unity Physics. Дверной BoxCollider берётся по UCX, не по ручкам.
Его минимум X при движении >=0.545 м, рама тестового Unity prefab <=0.53 м:
минимальный разделяющий зазор по X составляет 15 мм.
